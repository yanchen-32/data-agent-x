# DataAgentX 项目章程 — DAX-RB-1.2.1

当前设计基线DAX-RB-1.2.1；SRS/优先级v1.2与三项需求补充共同定义需求。原版审查、原始材料与旧工程状态留在内部归档，不随公开快照提供。设计定版不代表业务方签署或应用验收。

## 项目目标与定位

An Evidence-Grounded Business Data Investigation Agent.

核心任务是模拟电商数据的异常调查与贡献因素定位：明确口径、质量检查、受控查询、确定性贡献分析、证据核验与报告。开放业务解释仅作待验证假设；不承诺真实因果根因证明。核心流程为Clarify → Plan → Retrieve/Act → Verify → Report；Memory为条件增强。

## R0场景与边界

固定合成快照、单品单次成功支付订单，比较两个已成熟历史支付窗口的固定H退款率；H=7天/UTC为合成默认，必须检查as_of与水位。最近一周未成熟支付队列不在该指标适用范围；不得偷偷换窗或用退款事件数除当期支付单冒充队列率。

支持一个服务端授权地区过滤，冻结在Scope，先过滤后按品类/渠道/地区单维聚合；外部显式offset时间规范为内部UTC。R0不收candidate_sql。

Python/FastAPI/PostgreSQL单应用为主；QuerySpec→受信模板SQL，明确受限查询规划而非通用Text-to-SQL。数据库只读、两用户域隔离、注入防护、确定性数值、必要证据、唯一终态、显式REST取消、SSE观察、创建幂等、重启不重放、本地预算与脱敏为核心。

## 工程与评测

先独立Oracle/规则数据链路，再有界Mock，再真实LLM多步骤规划。B0获得相同工具、知识、报告/核验与规则分支；B1单次工具计划、B2反馈式计划。按预先冻结simple/dynamic标签比较质量、成本、延迟与配对区间；dynamic盲测至少30且五机制各至少6，+5pp仅收益候选，无收益/不确定结论也保留。

正式120独立case、30/30/60、三轮与原B2每轮48/60及六类各7/10门槛保留；先10–20边界、20–30集成、30–60预演逐步建设。检索数值门槛由CAL-R01预实验后、正式冻结前登记，相关集上界与多指标公开；盲测后不调低门槛。

预算默认audited：模型≤8/工具≤12/执行≤120秒，本地输入估算/请求输出上限20000/4000原子预留，未知usage保守记账；外部隐藏Token/计费/在途单列，不谎称供应商实际严格上界。strict_calibrated只有验证上界后宣称。queue累计30秒/active120秒/人工澄清1800秒分账且不重置，端到端单列。取消2/5/10秒分别实测，不靠接口状态替代。CAL-P01须先冻结有效负载、接收/完成/吞吐/等待/拒绝门槛。正式raw_run完整脱敏轨迹/usage/证据/评分在普通TTL前封存并读回重评分，封存后180天独立保留。
