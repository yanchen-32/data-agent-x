# DD01 身份权限与生命周期 v1.2

日期：2026-10-09；基线DAX-RB-1.2。状态：设计规格已修订，应用实现/运行验收待完成。控制依据：[SRS v1.2](../01_需求基线/DataAgentX_SRS_v1.2.md)。本版完整替代同模块v1.0/v1.1实施指导，旧版保留历史。

<a id="auth"></a>
## 1. 身份和授权

服务端配置高熵Bearer校验表示、principal_id/role/allowed_domains/capabilities/enabled/auth_version；秘密外部注入，常量时间比对。R0不建设注册/密码/SSO。客户端body、模型、知识内容不能赋予角色、域、数据库连接或区域授权。

| 主体 | 允许能力 | 约束 |
| --- | --- | --- |
| analyst_a / analyst_b | 分别domain_a / domain_b的创建、本人任务/证据/报告读取、澄清/取消 | 每次请求重新核查当前域、所有权和对象关系；不能借同名ID跨域 |
| operator | 已授予的import/purge、指定范围维护 | 运维身份不自动有业务内容读取或接管权 |
| 内部TTL作业 | 固定策略清理与最小账目维护 | 不是模型工具，不能创建调查 |

顺序：认证→当前域权限→对象归属→关系→状态/额度。401无效凭据，403明确未授权域/地区请求，404隐藏他人task/evidence/report。HTTP和SSE同一Bearer规则；观察断开不取消。原生CLI为核心，浏览器如选Could使用内存token与fetch流。外部部署需TLS，本地loopback。SC-01控制WS默认关闭，不需租约/token/恢复才执行调查。

<a id="revocation"></a>
## 2. 撤销和导入

凭据/域权限更新递增auth_version，后续读取拒绝，活动任务关闭新发并failed/AUTH_REVOKED；已发迟到结果只作隔离审计。地区ID由服务端映射到授权域/快照目录；业务过滤不是权限隔离的替代。快照/知识只能由受信CLI导入，校验ID/版本/域/有效区间/hash，staged→approved或quarantined。同版本异内容拒绝。知识里的指令始终是数据，不能扩大工具/权限。

固定业务域只读角色、应用库凭据与导入身份分离；模型不能读raw/app_state。知识/缓存/证据/报告/轨迹/受管理导出继承域和主体；缓存命中重授权，不跨用户共享结果。

<a id="lifecycle"></a>
## 3. 保留与清理

| 对象 | 起点和期限 | 清理规则 |
| --- | --- | --- |
| 普通脱敏详细trace | 终态后7天 | 正式run原始证据已验证封存才允许删对应在线副本 |
| 普通任务/scope/聚合证据/报告/调用汇总 | 终态后30天 | 按所有权清内容/缓存；不删除独立登记正式归档 |
| 创建/澄清幂等 | 首次受理24小时 | 原内容被清理后只留最小已删除标记至原期限；同key返回409 REQUEST_RESULT_DELETED |
| 正式合成评测raw_run/发布包 | 封存后180天 | 独立用途/域/所有者/访问和到期登记；到期清理或明确续期 |
| 固定快照/审核知识 | 显式退役 | 活动引用不能覆盖；正式归档保留足够版本/输入以复算 |

正式归档至少保留脱敏事件时间轴、调用参数的安全业务表示、模型版本/提示模板版本与可公开决策摘要、已发/未知usage/预留/结算、各证据payload/hash/依赖、报告Claim、private_label隔离副本、评分程序/结果与版本、配置/种子/原始输入manifest。默认不采集原始Provider提示响应或私有思维链；可复核的是动作/证据/评分，不能承诺从随机远端响应逐token重放。由run登记在任务创建时标记归档义务，终态后即导出；hash清单+读回+重评分通过才sealed。未封存阻止该run TTL删除并告警，限期人工处置，不宣称无界保留是解决方案；公开脱敏包与私有标签/受控轨迹分离。

R0无公开DELETE调查接口、无备份。受信operator先标内部deleting、拒绝读取/新发→取消/清理→删内容/缓存/普通受管理导出；正式评测归档是独立登记数据集，应按用途终止决定同步撤销，不随普通在线TTL误删。未知usage留非内容必要账目，迟到不能复建正文。用户下载副本不在服务端可删除范围。SC-02高级恢复/加密备份只有选定后另验，默认不依赖复杂墓碑重放。

<a id="audit"></a>
## 4. 审计验收

诊断日志白名单task/call/requestID、域、版本hash、状态/错误、时间、usage和短决策摘要；不记凭据/连接串/订单原始明细/原始提示。受控任务内容仍按授权保存允许业务字段。T08验证两域同名ID、地区越权、operator越权、撤销在途、知识注入、缓存隔离和日志密钥植入；T11验证全任务关联与正式归档180天、在线TTL/读回/重评分。SC-02未选不列核心恢复验收。
